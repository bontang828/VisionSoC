% Synthesis-only study (KV260, Vivado 2025.2, -s -a). Three configs differ
% only in dLen (and the VLEN / 2D grid that scales with it): laneScale is
% chosen so Lane_num = 2 in all three (2 lanes <-> 2 dual-port BRAM ports),
% and each SharedVRF bank is an explicit XPM block-RAM (xpm_memory_tdpram,

%   LUT 117,120 | FF 234,240 | DSP 1,248 | BRAM36 144 | URAM 64.
%
% Values > 1000 are shown in "k"; the raw integers are kept in a trailing
% "% raw:" comment on each such row for easy editing.
%

% environment into your report. Caption is at the bottom.
