FOVEA RVV²

A camera that thinks in whole pictures — and answers in software you already know.

Why “FOVEA”? The fovea is the eye’s sharpest spot, where the retina senses and computes — right at the sensor. So does this chip. (Focal-plane On-sensor VEctor Architecture.)

The problem · why near-sensor

Cameras fire millions of pixels per frame. We ship them all to a distant GPU, burn power moving data — then throw most away. FOVEA computes where the image is born; only the answer leaves.

RISC-Vopen chip standard

RISC-V is an open, royalty-free instruction set — the open answer to Arm and x86. Its vector extension (RVV) is the standard SIMD muscle. FOVEA is an RVV machine, so your code is the same vector code every RISC-V chip understands — not a one-off DSL.
