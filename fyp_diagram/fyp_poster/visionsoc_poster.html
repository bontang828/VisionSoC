VisionSoC

A camera that thinks in whole pictures — a vision processor built on open RISC-V silicon.

RISC-V open chip standard

RISC-V is an open, royalty-free design for processors — the open-source answer to Intel and Arm, that anyone can build a chip around. Its vector extension adds the muscle to crunch many numbers at once. VisionSoC takes that vector engine and reshapes it so an entire camera image becomes a single instruction — then runs the whole thing as a live camera → chip → screen system on one FPGA board.

The end-to-end system  ·  capture → process → display, live

The big idea

One instruction, a whole image

An ordinary processor touches a handful of pixels per instruction. VisionSoC's vector engine is wired as a 2-D fabric: every instruction is broadcast across 128 hardware rows at once, so a single load pulls in a complete 128×128 frame — 16,384 pixels — and a single add, multiply or filter step works on all of them in parallel.

One vle8.v load = all 128×128 pixels lit at once. That's where the "free" parallelism — and the real-time speed — comes from.
vle8.v v8, (frame) // pull in the entire image — 16,384 px vadd.vv v8, v8, v8 // one op brightens every pixel together

Looking in two directions

2-D filters, no data juggling

A single mode switch lets the same instructions sweep across a row or down a column. That's what makes 2-D image operations — edges, blur, motion — cheap and natural, instead of needing to rearrange the image first.

Horizontal mode

left ⟷ right. Compare each pixel with its neighbours along the row.

Vertical mode

up ⟷ down. The same op now compares across image rows — for free.

How the system runs

A real, live pipeline

A real camera streams frames into memory. The RISC-V V core — living inside the FPGA fabric — runs a small kernel (program) on each frame and writes the result straight back out to an HDMI monitor, ~20 times a second.

It's driven by plain C on bare Linux running on the board's Arm cores — a handful of register writes, no heavyweight framework. Swapping in a new vision algorithm is just swapping the kernel.
